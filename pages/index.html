Install

Finch installs to your device from this page so you can open the app anytime.

Install Finch here

Use the button on this page. The browser saves Finch as an app icon and that icon opens the app runtime.

Why install this way? Finch installs as a clean web app, so it creates a normal app icon without changing your system settings, adding hidden background software, or putting a giant app-store layer between you and the tool. We also do not support an app-store ecosystem that can take up to 30% of your cost. Keeping Finch outside that layer helps keep the price down so we can pass that on to you.

iPhone / iPad (Safari)

  1. Look at the bottom toolbar.
  2. Tap the Share icon, the square with the up arrow. If your layout shows •••, tap that first, then tap Share.
  3. Scroll down the sheet.
  4. Tap Add to Home Screen.
  5. Tap Add.
If you do not see “Add to Home Screen,” check that you are on the Finch app page in Safari.

Android (Chrome)

  1. Tap the ⋮ menu.
  2. Tap Install app or Add to Home screen.
  3. Tap Install or Add.

Mac Safari

  1. Use the top menu bar.
  2. Click File, then Share.
  3. Click Add to Dock....
  4. Click Add.

Microsoft Edge

  1. Click the ... menu.
  2. Go to Apps, then Install this site as an app.
  3. Click Install.

Windows Chrome

  1. Click the Install icon in the address bar.
  2. Click Install.
